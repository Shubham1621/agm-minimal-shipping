# Contributing

Useful contributions include reproducible code fixes with regression tests, alternative pinned-model runs that preserve their own qualification and held-out cohorts, and substantive critique of the framework or its measurement assumptions. Please include the command run, the observed output, model/version details where relevant, and any limits on what the evidence supports. Small, reviewable changes are preferred; synthetic data and personal cloud resources only.

Please do not claim that the experiment has run unless there is a committed run record that supports the claim. Do not change the preregistration, acceptance thresholds, task allocation, scoring rubric, or stopping rules in place; proposed changes should be raised separately and timestamped before any affected new scored cohort begins. Alternative thresholds can be discussed as future research, but they must not be retrofitted to the current cohort.
